# Cognifyz-Web-Developer-Internship-LEVEL-2-TASK-1
# Level 2 - Task 1: Front-end Frameworks 🚀

## Project Overview

This project is created as part of the Cognifyz Technologies Web Development Internship.

The task focuses on using front-end frameworks to create responsive UI components and layouts.

## Features

### 1. Responsive Card Component

A responsive card component has been created using a front-end framework.

The card contains:
- An image
- Text content
- A button

### 2. Responsive Grid Layout

A responsive grid layout has been implemented using a front-end framework.

The grid automatically adapts according to different screen sizes.

## Framework Used

- Bootstrap 5

## Technologies Used

- HTML5
- CSS
- Bootstrap

## How to Run

1. Open the `index.html` file.
2. Run it in any modern web browser.
3. Resize the browser window to check the responsive card and grid layout.
